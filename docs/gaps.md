## Differences on working features

- `photo.layer.basics`: PSD stores opacity and fill in one byte each; a reopened file numbers its layers afresh.
- `photo.layer.object-layer-basics`: A reopened placed layer is linked to the uuid of the file the PSD carries for it, embedded or not; Photoshop shows it as embedded.
- `photo.type.point-text`: EngineData stores numbers with five decimals; a run without a PostScript name gets the one its family and weight give.
