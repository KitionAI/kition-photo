### Optional build input: kition-fonts (not files in this repo)

Native builds made with `KITION_FONTS_DIR` (official headless releases) embed every font in
[KitionAI/kition-fonts](https://github.com/KitionAI/kition-fonts)' `fonts/manifest.txt` at a pinned
commit; the web package embeds none and ships Droid Sans Fallback as a separate file in `fonts/`
with its NOTICE. No font file from kition-fonts is committed here. Per-file authors, sources and
licences: [kition-fonts `ATTRIBUTION.md`](https://github.com/KitionAI/kition-fonts/blob/main/ATTRIBUTION.md).

| Font (from kition-fonts) | Where it ships | License |
|---|---|---|
| Droid Sans Fallback | web package `fonts/`; native builds (embedded) | Apache-2.0 |
| Inter, Lora, JetBrains Mono, Bricolage Grotesque, Carlito, Caladea, Tinos, Cousine, Arimo, Noto Color Emoji, Ma Shan Zheng | native builds (embedded) | SIL OFL 1.1 |

The other built-in ICC profiles and the generated LUT looks are produced by code at runtime
(`crates/support/cms/src/builtin.rs`, `crates/support/cms/src/lutfile.rs`) and dedicated to the public domain
(CC0-1.0); they are not separate files.
